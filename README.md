Kirim va chiqimni hisoblaydigan prilojeniye.

Ushbu loyiha foydalanuvchilarga o'zlarining kirim (`Income`) va chiqim (`Expense`) xarajatlarini boshqarish, tahrirlash (`PUT`), o'chirish (`DELETE`) hamda 3 ta tilda (`uz`, `ru`, `en`) foydalanish imkoniyatini beruvchi RESTful API hisoblanadi.

🛠 Texnologiyalar
- **Python / Django & Django REST Framework (DRF)**
- **JWT Authentication** (`djangorestframework-simplejwt`)
- **Multi-language Support** (`LocaleMiddleware`)
- **API Documentation:** Swagger / Redoc
